# The Painting I Did When I Was 7

By Melinn (Supitcha Chailom)

[View this project online](https://mightymelinn.github.io/cart253/instructions-challenge/instructions-challenge/)

## Description

This project is an exploration designed to build technical familiarity with p5.js. The night sky drawing is a foundational exercise in programming drawing, reminded me of the feeling of opening Paint for the first time.
