# I Against Me: Web Walking Sim 👻

A browser-based first-person horror walking sim set in the world of **[I Against Me](https://store.steampowered.com/app/3803600/I_Against_Me/)**, built with **[three.js](https://threejs.org/)** for CART 253 (Fall 2026).

[![Play on GitHub Pages](https://img.shields.io/badge/Play-GitHub_Pages-black?style=for-the-badge&logo=github)](https://mightymelinn.github.io/cart253/)

---

## What I'm building

A first-person horror walking sim inspired by **[P.T.](https://www.youtube.com/watch?v=YbaTFXlBllI)**, built in three.js with a house and models imported from my UE5 project (FBX). The player explores the house to find **3 items** while an entity follows the player every frame. Each item triggers a scripted horror event. Collecting the third item ends the game with a letter containing a Steam wishlist link and an email signup for exclusive contents.

Everything is built in **one ongoing project**. Each week adds new features using that week's concept, and the reflective journal documents what was added.
